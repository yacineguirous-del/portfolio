Épreuve E4 — Veille Technologique

L'Intelligence Artificielle Générative dans le Développement Logiciel et la Cybersécurité

Analyse approfondie de l'impact des modèles génératifs et des assistants conversationnels (LLM) sur les pratiques de développement web et les nouveaux enjeux de sécurité des applications.

1. Transformation du Code & Productivité

L'intégration d'outils comme GitHub Copilot ou ChatGPT révolutionne le quotidien du développeur SLAM :

  • Génération automatique de requêtes SQL complexes et de structures CRUD.
  • Rédaction accélérée de tests unitaires et de documentation technique.
  • Réduction du code boilerplate au profit de la logique métier.

2. Risques & Vulnérabilités Applicatives

Malgré leurs avantages, les IA génératives introduisent de nouveaux vecteurs de risque soulignés par l'OWASP :

  • Introduction involontaire de failles (injections SQL, XSS) dans le code généré.
  • Risque d'hallucination syntaxique nécessitant une relecture humaine rigoureuse.
  • Exposition accidentelle de données sensibles ou de clés API d'entreprise.

3. Méthodologie & Outils de Veille

Mise en place d'un processus rigoureux de curation et d'analyse continue :

  • Agrégation de flux RSS spécialisés (ANSSI, OWASP, GitHub Blog, Medium).
  • Alertes automatisées via Google Alerts sur les failles LLM.
  • Rédaction de fiches de synthèse trimestrielles pour l'épreuve E4.

Conclusion de la Veille

L'intelligence artificielle n'a pas vocation à remplacer le développeur, mais à devenir un co-pilote puissant. La maîtrise des bases de la programmation (acquise en BTS SIO SLAM) et des principes de cybersécurité (certifications Cisco & ANSSI) reste indispensable pour auditer, valider et sécuriser le code produit.
